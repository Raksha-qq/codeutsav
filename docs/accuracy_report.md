## Known limits

- Width resolution is one pixel (0.5 mm here); a median of identical integer widths quantises to 0.5 mm. Zoom in (or use sub-pixel edge fitting) if a ±1.0 mm tolerance must be verified to better than ~0.4 mm.
- The repeatability σ reflects sensor-noise repeatability of the algorithm on identical geometry; it does not include mechanical variation (vibration, belt wander) or re-seating the prop.
- `data/raw/demo.mp4` is not used here: its burned-in labels (1000 × 130 mm) are inconsistent with its own ArUco marker (0.52 mm/px → the bar is ≈ 323 × 133 mm), so it has no usable ground truth.
- No OCR engine (PaddleOCR / EasyOCR / Tesseract) is installed in this environment, so the **builtin template-matching fallback** produced the OCR figures. It is tuned to clean printed IDs; the test set and belt scene use fonts it was built from, so these OCR numbers are optimistic. Install PaddleOCR or EasyOCR and re-run this script and `scripts/ocr_eval.py` to measure real stamped/painted IDs.
